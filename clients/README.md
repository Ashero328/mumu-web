# clients／客戶的東西

**做給客戶的成品都放這裡，一家一包**——賀卡、單頁網站都算。

> **跟 `cards/` 怎麼分：**
> `cards/` 只放**木木自己的範本卡**（拿來展示、給人看樣式的）；
> **客戶的**一律進 `clients/`。
>
> | | 放什麼 | 現在有 |
> |---|---|---|
> | `cards/` | 木木自己的範本卡 | `CH2026001` 聖誕、`NE2026001` 西元新年 |
> | `clients/` | 客戶的成品（賀卡／網站） | `songchuan` 松川珈琲（賀卡示意） |

## 結構（一家一個資料夾）

代號用**英文小寫**，取公司名好認即可（`songchuan`、`acme`…）。

**賀卡**（跟 `cards/` 用同一套引擎）：

```
clients/
└─ songchuan/
   ├─ index.html        ← 卡片內容與檔期設定都在這裡
   ├─ list.jpg          ← 總站列表圖 540×960
   ├─ css/              card.scss（版式引擎）＋ style.scss（這張卡的風格）
   ├─ scripts/          card.js（引擎）＋ anim.js（動畫）＋ gsap/
   └─ images/           logo.svg（客戶標記）、poster.jpg（OG 分享 1200×630）
```

**單頁網站**：

```
clients/
└─ acme/
   ├─ index.html        ← 單頁，內容自己編
   ├─ css/              style.scss / style.css
   ├─ scripts/          main.js ＋ jquery/ owl-carousel/ gsap/（自帶，不共用總站的）
   └─ images/
```

網址：`木木網域/clients/<代號>/`

**網站預設就是一頁。** 真的需要第二頁時，`about.html`、`products.html` 這種頁面
**與 `index.html` 放同一層**，共用同一組 `css/` `scripts/` `images/`，不另外開資料夾。

外掛一包一資料夾、用外掛名命名、**css 與 js 放同一個資料夾不分家**，整包收在 `scripts/` 底下。

> **這個 repo 裡沒有預備骨架。** 內容與版型由我們自己視每家客戶決定，
> 先放一份空的資料夾比放一份猜錯方向的樣板有用。
>
> 另有一份做完、驗過的**單頁網站**範本（咖啡焙煎所，暗底＋橙），
> **刻意不放在這個公開 repo 裡**，收在專案資料夾的 `網頁範本\songchuan\`。
> 要用就整包複製進來改；它自帶 jQuery／Owl／GSAP，複製進來就能跑。

## 鐵律：完全自足

**每一包都不准引用總站的任何檔案**——不寫 `../../scripts/`、不寫 `../../images/`。
外掛多佔幾百 KB 是刻意付的代價，換到的是：

- 這家公司哪天要搬到自己的網域，整個資料夾複製走就能跑，不用回頭補檔
- 總站改版、換外掛版本、調整樣式，都不會意外弄壞客戶的東西
- 客戶那邊出問題時，排查範圍就是那一個資料夾

## 新增一家（SOP）

**賀卡**：複製一張現有的卡（`cards/` 或 `clients/` 裡任一張）到 `clients/<代號>/`，
改 `index.html` 標了 ✏️ 的字、`css/style.scss` 的風格、`scripts/anim.js` 的動畫，
然後編譯。**`og:url` 與 `og:image` 一定要換成新路徑**——
爬蟲只讀原始碼、不執行網頁，忘了改的話 LINE 預覽會抓到別張卡（或 404）。

**單頁網站**：

1. `clients/` 底下開新資料夾，用公司代號
2. 建 `index.html`、`css/`、`scripts/`、`images/` 四樣
3. 需要 jQuery／Owl／GSAP 的話，把總站 `scripts/` 裡對應的外掛資料夾**整包複製**進去（不是引用）

編譯（兩種都一樣）：

```
npx sass --update clients/<代號>/css:clients/<代號>/css --no-source-map
```

## 上線前要先講清楚的一件事

掛在子路徑（`木木網域/clients/acme/`）起步最快，但**那家公司日後要換成自己的網域時，整組網址會變**，得做轉址，搜尋排名也會斷一次。

如果一開始就知道這家公司之後會獨立，建議直接給**子網域**（`acme.木木網域`）：
Cloudflare 上設定一樣簡單，日後搬家網址結構完全不用動。差別只在現在多設一次 DNS。

> 賀卡沒有這個問題——賀卡是一次性的，連結發出去就固定了，不會搬家。
> 但也因為連結會躺在別人的 LINE 對話紀錄裡，**路徑一旦發出去就不能再改**。
