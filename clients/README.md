# clients／代管公司網站

暫時掛在木木文化網域底下的**其他公司網站**，一家一包。

> 這裡跟 `cards/` 沒有關係。`cards/` 是木木自己的電子賀卡作品，
> 這裡是別家公司的完整網站。

## 結構（一家一個資料夾，**預設單頁**）

代號用**英文小寫**，取公司名好認即可（`acme`、`sunho`…）。

```
clients/
└─ acme/
   ├─ index.html        ← 單頁，內容自己編
   ├─ css/              style.scss / style.css
   ├─ scripts/
   │   ├─ main.js       自己寫的
   │   └─ owl-carousel/ owl-carousel.min.css ＋ .min.js（自帶，不共用總站的）
   └─ images/           這家公司自己的圖
```

網址：`木木網域/clients/acme/`

**預設就是一頁。** 真的需要第二頁時，`about.html`、`products.html` 這種頁面
**與 `index.html` 放同一層**，共用同一組 `css/` `scripts/` `images/`，不另外開資料夾。

外掛一包一資料夾、用外掛名命名、**css 與 js 放同一個資料夾不分家**，整包收在 `scripts/` 底下。

> **目前沒有預備骨架。** 內容與版型由我們自己視每家客戶決定，
> 先放一份空的資料夾比放一份猜錯方向的樣板有用。要開第一家時照下面的 SOP 建就好。

## 鐵律：完全自足

**每一包都不准引用總站的任何檔案**——不寫 `../../scripts/`、不寫 `../../images/`。
外掛多佔幾百 KB 是刻意付的代價，換到的是：

- 這家公司哪天要搬到自己的網域，整個資料夾複製走就能跑，不用回頭補檔
- 總站改版、換外掛版本、調整樣式，都不會意外弄壞客戶的網站
- 客戶網站出問題時，排查範圍就是那一個資料夾

## 新增一家（SOP）

1. `clients/` 底下開新資料夾，用公司代號
2. 建 `index.html`、`css/`、`scripts/`、`images/` 四樣
3. 需要 jQuery／Owl／GSAP 的話，把總站 `scripts/` 裡對應的外掛資料夾**整包複製**進去（不是引用）
4. SCSS 照鐵律編譯：`npx sass --update clients/acme/css:clients/acme/css --no-source-map`

## 上線前要先講清楚的一件事

掛在子路徑（`木木網域/clients/acme/`）起步最快，但**那家公司日後要換成自己的網域時，整組網址會變**，得做轉址，搜尋排名也會斷一次。

如果一開始就知道這家公司之後會獨立，建議直接給**子網域**（`acme.木木網域`）：
Cloudflare 上設定一樣簡單，日後搬家網址結構完全不用動。差別只在現在多設一次 DNS。
