# 松川珈琲焙煎所（示範包）

**這是虛構的示範品牌**，用來當 `clients/` 的版型起點。
品牌名稱、地址、電話、價格全部是假的。

預覽：`木木網域/clients/songchuan/`

## 拿它開新客戶

```
cp -r clients/songchuan clients/新代號
```

複製完照下面的順序改，改完編譯：

```
npx sass --update clients/新代號/css:clients/新代號/css --no-source-map
```

### 1. `index.html` —— 標了 ✏️ 的地方

| 位置 | 內容 |
|---|---|
| `<title>` `<meta name="description">` | 分頁標題與搜尋結果的描述 |
| `og:*` 五行 | 分享到 LINE／FB 的預覽。**網域確定後要換成正式的絕對網址** —— 爬蟲只讀原始碼、不執行網頁，相對路徑它找不到基準 |
| `.brand` / `.foot__name` | 品牌中英文名 |
| 導覽 `.nav__links` | 刪一項就要把對應的 `<section>` 一起刪 |
| 主視覺 | 三行主標（**盡量維持字數**，錯落的節奏是版面的一部分）、主張、兩顆按鈕、三欄規格 |
| 各段大標與內文 | 段落編號 `01`–`04` 也要跟著調 |
| `.bean` | 一支商品一個 `<li>`，複製或刪除整個 `<li>` |
| `.shot` | 一張照片一個 `<figure>` |
| `.info__row` | 營業資訊 |
| **`.foot__demo`** | **接真客戶時把這一行整個刪掉**（style.scss 裡的 `&__demo` 也可以一併刪） |

### 2. `css/style.scss` —— 大部分只要動最上面的 Tokens

顏色、版面寬度、區塊留白都集中在 `:root`。改色系基本上只動 `$bg` `$ink` `$accent` 這幾個。

> **全站字級下限 12px**（含定值與 clamp 的下界）。等寬小標統一走 `--fs-micro`，
> 不要各自寫 `.62rem`／`.66rem`，那會一路縮到讀不動。

> ⚠️ **巢狀 `@media` 一律放在該規則的最後一行。**
> Sass 會把媒體查詢後面的宣告收成第二條同名規則排在它之後，
> 權重相同、位置在後 → 媒體查詢裡寫的會整條被蓋掉。症狀很像「樣式沒套到」。

### 3. `images/`

- `logo.svg` —— 品牌標記。換成客戶的檔案，**維持 1:1 的視框**。
  標記裡不放文字：SVG 裡的字會被使用者的系統字體影響，換一台電腦就走樣，
  所以中英文名是用網頁字體排在 HTML 裡的。
- `slide-1~4.svg` —— 照片佔位圖（1200×900）。換成同名 `.jpg` 並改 `index.html` 的 `src`。

### 4. 字體

`index.html` 的 Google Fonts 那行載了四套：
Fraunces（拉丁標題）、Noto Serif TC（**中文標題**）、Noto Sans TC（內文）、DM Mono（規格小標）。

> Fraunces 沒有中文字，中文標題會落到 Noto Serif TC。
> **那支一定要一起載**，否則會改吃使用者電腦裡的系統明體。
> 載入的字重要對得上 CSS 用到的（目前是 600 與 900）。

## 這一包遵守的規則

- **完全自足**：不引用總站的任何檔案。jQuery／Owl／GSAP 都在 `scripts/` 底下，
  整個資料夾複製走就能跑
- **輪播一律 Owl**，不自己寫。初始化參數在 `scripts/main.js`
- **動態一律 GSAP**，全部包在 `prefers-reduced-motion: no-preference` 之內；
  關掉動態時那一段完全不執行，內容維持 CSS 的預設狀態（本來就看得見）
- **只改 `.scss`**，`.css` 是編譯產物
