# 電子賀卡：可以自己改的地方

給琇端。每張卡都是一個資料夾（例如 `CH2026001`），裡面的東西長這樣：

```
CH2026001/
├─ index.html     ← 文字、日期都在這裡面改
├─ list.jpg       ← 總站列表上顯示的圖
├─ images/        ← 這張卡用到的圖
├─ css/           ← 外觀（不用動）
└─ scripts/       ← 程式（不用動）
```

**你會用到的只有 `index.html` 和 `images/` 這兩個。**

---

## 一、開檔案

`index.html` 用**記事本**就能開（在檔案上按右鍵 → 開啟檔案 → 記事本）。
如果會用 VS Code 之類的編輯器更好，字會有顏色比較好認。

打開之後不要被一堆符號嚇到，**你只要找有 `✏️` 這個鉛筆記號的地方**，
每個記號下面那一行就是可以改的內容。沒有記號的地方請不要動。

---

## 二、改文字

找到 `✏️ 可以改` 的段落，把**兩個 `>` `<` 中間的字**換掉就好。

```html
<!-- ✏️ 可以改：祝福語 -->
<p class="card-greeting">願這個冬天的燈火，照亮你一整年的溫柔與勇敢。</p>
                        ↑ 改這裡的字 ↑
```

一張卡上可以改的文字有六個：

| 記號寫的 | 在畫面上是哪一段 |
|---|---|
| 這張卡的標題 | 瀏覽器分頁上顯示的字（不在畫面裡） |
| 大標題 | 最上面那行金色的英文，斜體 |
| 副標 | 英文底下那行中文，字距很開 |
| 祝福語 | 中間的主要句子 |
| 落款 | 祝福語下面的署名 |
| 卡片下方的說明文字 | 往下滑之後那段小字 |

**不需要某一行就把整行刪掉**，畫面會自己收合，不會留一塊空白。

⚠️ 只改字，**不要刪掉 `<p ...>` 和 `</p>` 這些角括號**，刪到會讓版面跑掉。
不小心改壞了不要緊，跟我說一聲，我這邊有備份可以還原。

---

## 三、換圖片

把新圖**用一模一樣的檔名**蓋掉 `images/` 資料夾裡的舊圖就好，不用改任何程式。

| 檔名 | 用途 | 尺寸 |
|---|---|---|
| `images/poster.jpg` | 分享到 LINE 時顯示的預覽圖 | 1200 × 630 |
| `list.jpg`（在卡片資料夾最外層） | 總站列表上的卡片圖 | 540 × 960 |

尺寸不一樣也能用，但會被裁切或留白，**照著尺寸做最漂亮**。

---

## 四、設定檔期（到期自動收起）

在 `index.html` 最上面，找到這一段：

```html
<meta name="card-offline" content="">
```

把日期填進雙引號中間，格式是 **年-月-日**：

```html
<meta name="card-offline" content="2027-02-28">
```

過了這天之後，這張卡會自動變成一頁「這張賀卡的檔期已經結束了」的公告，
上面有回到最新賀卡的連結。

**網址不會失效**——客戶之前轉發出去的連結還是打得開，只是看到的是公告頁。
這很重要：賀卡會躺在別人的 LINE 對話紀錄裡，過很久還可能被翻出來點開。

**留空就是永遠不下架。**

---

## 五、客戶的曝光 banner

有賣曝光的卡，在 `index.html` 找到「客戶曝光區」那一段，把註解符號 `<!--` 和 `-->` 拿掉，
然後填上圖檔名和客戶網址：

```html
<aside class="card-promo">
  <a href="https://客戶的網址" target="_blank" rel="noopener">
    <img src="images/promo-banner.jpg" alt="○○公司 新春優惠" width="1200" height="300">
  </a>
</aside>
```

banner 圖放進這張卡的 `images/` 資料夾。

曝光有檔期的話，填上面那段的第二個日期：

```html
<meta name="promo-offline" content="2027-01-31">
```

過了這天**只有 banner 消失，賀卡本身照常**。

沒有賣曝光的卡，這整段留著不管它就好，空的會自動隱藏。

---

## 六、改完之後

改完存檔，把整個卡片資料夾傳給我，我上傳到網站上。
**不要直接改線上的版本**，那是我這邊部署上去的，改了會在下次上傳時被蓋掉。

流程：妳改好 → 傳給我 → 我上傳並回傳預覽連結 → 妳確認 OK → 正式生效。

---

## 絕對不要動的

- `css/` 和 `scripts/` 兩個資料夾裡的任何檔案
- `index.html` 裡沒有 `✏️` 記號的段落
- 檔名（尤其是 `poster.jpg`、`list.jpg`，改名就抓不到了）
