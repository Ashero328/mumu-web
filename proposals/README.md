## A_留白（主案・已依回饋改版）

**中式文青・留白**。方向定調，後續內頁以此為準。

- **版面範圍**：內容上限放寬到 **1920px**（原 1180 太窄），寬螢幕仍有左右細界線提示邊界；作品與內文另有行寬上限，加寬不影響閱讀
- **中式元素**：宣紙白底、明體標題、朱紅印章（只留主視覺右下的「木」）、方正無圓角
- **配色**：改以琇端偏好的**綠色為主軸**（主綠 `#6F8544`／深綠 `#4A5A34`／橄欖綠 `#97A675`／淺薄荷 `#D6EAD4`），用色克制，**多數顏色變化發生在 hover**；聯絡區改深綠底
- **營業項目＝圓圈關係圖**：中心綠圓向外六個薄荷圓，圓內放 icon，細綠線連接；**滑過圓圈變深綠、icon 反白、對應連線加亮**；手機轉為垂直脈絡
- **訂購流程（新增）**：聊需求 → 報價確認 → 設計審稿 → 印製交付，四步各有 icon 與編號，桌機以細線串連
- **設計作品＝小而精美**：四張真實名片情境照，4:3 等尺寸，滑過微微上浮
- **賀卡檔期＝疊卡捲動**（把 B 案的動態移過來）：四張真實賀卡直式圖，一張蓋一張
- **裝飾素材**：`about` 區右下的**水彩樹**（品牌「木木」意象，淡淡襯底，1100px 以上才出現）；聯絡區上緣的**波浪草皮 SVG**，讓紙面自然過渡到深綠
- **資訊收斂**：理念段落精簡、聯絡資訊改為 icon＋標籤四欄

### icon 與素材

- `assets/icons/`：12 個 icon。**營業項目與訂購流程用黑色線稿**（hover 以 `filter: invert(1)` 反白）；**聯絡區是彩色品牌 logo，保留原色不反轉**
- 要換 icon：覆蓋 `assets/icons/` 內的同名 PNG 即可，不用改程式
- `assets/tree.webp`：8.16 MB PNG 壓成 **150 KB WebP**（省 98%）
- `assets/hero-studio.jpg`：2 MB PNG 壓成 **177 KB JPG**
- `assets/illus/grass.svg`：波浪草皮，三層丘陵＋草叢，最前層與聯絡區同色

## 技術規格

- 色票：綠色-2 系（`#00738C` 深藍綠、`#97A675` 橄欖綠、`#D6EAD4`、`#EFEEDB` 米白）＋朱紅 `#A63A2E` 只用於印章
- **SCSS**：只改 `.scss`，`.css` 是編譯產物
  ```
  npx sass proposals/A_留白/css/style.scss proposals/A_留白/css/style.css --no-source-map
  npx sass proposals/B_幾何線條/css/style.scss proposals/B_幾何線條/css/style.css --no-source-map
  ```
- 動態一律 GSAP＋ScrollTrigger（`vendor/`），全部包在 `prefers-reduced-motion` 判斷內；關閉動態時內容照樣完整可讀
- 字體與圖片載入後會位移，已在載入完成時重算 ScrollTrigger 觸發點
- 已驗證：500px 與 1440px 都無橫向溢出；圖片比例、關係圖座標與曲線端點對齊
